## Source-of-truth order

When documents conflict, prefer them in this order:

```text
verified artifacts and current code
? PROJECT_STATE.md and crop handoff
? DECISIONS.md
? PIPELINE_SPEC.md
? PROJECT_CONTEXT.md
? historical notes under md files/
```

Historical Markdown files and legacy notebook outputs are useful records but do not override current corrected evidence.
